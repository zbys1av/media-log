# MEDIA / LOG — коротка пам'ятка

GitHub: https://github.com/zbys1av/media-log

Порядок налаштування:

1. Settings → Pages → main / (root).
2. Google Cloud → Google Auth Platform → Clients → Web application → Origin https://zbys1av.github.io.
3. GitHub fine-grained token → тільки media-log, Contents: Read and write.
4. Cloudflare → worker/wrangler.toml → Client ID → npx wrangler deploy → npx wrangler secret put GITHUB_TOKEN.
5. Cloudflare Worker URL і Google Client ID → cloud-config.js.
6. Відкрий https://zbys1av.github.io/media-log/, перевір хмару у налаштуваннях.
